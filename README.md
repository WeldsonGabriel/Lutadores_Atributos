# 🥋 Batalha de Lutadores (Java CLI)

## 🎯 Sobre o Projeto
**Batalha de Lutadores** é um mini game em **Java** desenvolvido para praticar **lógica de programação**, **POO** e **estruturas de controle**.  
O jogo simula uma luta entre dois personagens com **atributos aleatórios** e determina o vencedor com base no **poder total**.

O projeto é totalmente **executável no console (CLI)** e foi pensado para ser **simples, modular e escalável** — ideal para quem deseja estudar ou montar portfólio Java.

---

## ⚙️ Funcionalidades

- 🎲 Geração aleatória de lutadores com atributos únicos  
- 👊 Comparação automática de atributos  
- 🏆 Exibição do vencedor  
- 🔁 Geração de novos lutadores a qualquer momento  
- 🧱 Estrutura POO organizada (pacotes `app` e `model`)  
- 🧩 Menu interativo usando `switch-case`  

---

## 🧠 Conceitos Aplicados

| Conceito | Aplicação |
|-----------|------------|
| **POO (classes e objetos)** | `Lutador.java` |
| **Encapsulamento** | métodos privados e públicos bem definidos |
| **Arrays multidimensionais** | armazenamento e fácil expansão dos atributos |
| **Laços de repetição (`for`, `for-each`)** | geração e cálculo de atributos |
| **Switch-case** | controle de menu no `Main.java` |
| **Aleatoriedade (`Random`)** | valores dinâmicos de atributos |
| **Organização modular** | pacotes `app` e `model` separados |

---

## 📂 Estrutura de Pastas
```
src/
 ├── app/
 │     └── Main.java          → controle do fluxo e menu principal
 └── model/
       └── Lutador.java       → classe do lutador e seus atributos
```

---

## 🚀 Como Executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/BatalhaDeLutadores.git
   ```
2. Abra o projeto no **IntelliJ IDEA** ou em outro ambiente Java.
3. Execute o arquivo `Main.java`:
   ```
   src/app/Main.java
   ```
4. No console, selecione as opções do menu:
   - `1` → Mostrar lutadores  
   - `2` → Iniciar luta  
   - `3` → Gerar novos lutadores  
   - `4` → Sair
